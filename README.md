# Вопросы и ответы по Java

Подготовка к собеседованию Java Middle+ / Senior: 295 вопросов с короткими и развёрнутыми ответами — Java Core,
коллекции, многопоточность, JVM, Spring, JPA, PostgreSQL, Kafka, микросервисы, System Design, Kubernetes, практика
(code review и лайв-кодинг), опыт и лидерство, сети, безопасность, алгоритмы.

Всё в одном файле [`index.html`](index.html): без сборки, сервера и внешних зависимостей. Слева список вопросов с
поиском (по вопросам и тексту ответов), справа ответ выбранного; ← → — соседние вопросы, «/» — поиск.

Открыть: скачать `index.html` и открыть в браузере, или включить GitHub Pages (Settings → Pages → Deploy from a
branch → `main` / root).
