# Java-собеседование

Подготовка к собеседованию Java Middle+ / Senior: 322 вопроса — Java Core, коллекции, многопоточность, JVM, Spring,
JPA, PostgreSQL, Kafka, микросервисы, System Design, Kubernetes, практика (code review и лайв-кодинг), деньги и время,
сети, безопасность, алгоритмы, Git, Maven и Gradle, опыт и лидерство.

**Открыть: [bakigoal.github.io/java-interview](https://bakigoal.github.io/java-interview/)**

У каждого вопроса два блока:

- **Короткий ответ** — суть, которую стоит сказать вслух;
- **Подробнее** — нюансы, код, таблицы и что спросят следом.

Два режима. **Тренировка**: ответ скрыт — сначала вспомни, потом нажми «Показать ответ» и отметь себя: «Не знал», «Частично» или «Знаю». Отметки собираются в прогресс по главам, в итоге главы видно слабые вопросы, а фильтр «Повторить» оставляет только их. На ноутбуке: пробел — ответ, 1/2/3 — оценка. **Чтение**: ответы открыты, можно листать подряд. Прогресс хранится только в этом браузере.

Страница сделана в первую очередь для телефона: список глав с поиском по вопросам и тексту ответов, экран ответа с
кнопками «Назад / Далее» и свайпами. На широком экране — список слева и ответ справа (← → — соседние вопросы, «/» —
поиск). Светлая и тёмная тема (Atom One Light / One Dark Pro): по умолчанию как в системе, переключается кнопкой.

Страница — один файл [`index.html`](index.html), без сервера и внешних зависимостей — можно скачать и открыть в
браузере. На сайте её можно добавить на домашний экран телефона, и после первого открытия она работает без сети. Страница собирается в репозитории подготовки и публикуется сюда скриптом; вручную `index.html` не правится.
